# Multiple chart panels

## User story

As a BimmerLink user, I want to add, remove and reorder chart panels and assign parameters to them so that I can compare channels with very different scales in stacked views.

## Acceptance criteria

- [ ] 'Add panel' / 'Remove panel' controls; at least one panel always exists
- [ ] Parameters can be assigned to a panel from the list or by drag-and-drop
- [ ] Panel height adjustable
- [ ] Panel layout is part of the view state (see Session feature)

## Definition of done

- [ ] Tests added/updated (unit and, where relevant, e2e on the `Example/` logs)
- [ ] Lint, typecheck, tests and build pass in CI
- [ ] Docs / AGENTS.md updated if conventions changed
