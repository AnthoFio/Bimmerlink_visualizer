# Series colours and legend

## User story

As a BimmerLink user, I want distinct, editable colours and an interactive legend so that I can tell series apart and emphasise one.

## Acceptance criteria

- [ ] Auto-assigned colourblind-safe palette, stable per parameter across reloads
- [ ] Colour picker per series
- [ ] Legend click toggles visibility; hover highlights series, dims the others

## Definition of done

- [ ] Tests added/updated (unit and, where relevant, e2e on the `Example/` logs)
- [ ] Lint, typecheck, tests and build pass in CI
- [ ] Docs / AGENTS.md updated if conventions changed
