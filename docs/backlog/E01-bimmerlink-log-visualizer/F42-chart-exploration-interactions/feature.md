# Chart exploration interactions

Direct-manipulation tools to explore events inside a log: zoom, pan, synchronised cursor, tooltips and range statistics.

**Outcome:** the user can find a knock/misfire event and read exact values without leaving the chart.

- [S43](S43-zoom-and-pan-on-the-time-axis.md) Zoom and pan on the time axis (Backlog)
- [S44](S44-synchronised-zoom-and-cursor-across-panels.md) Synchronised zoom and cursor across panels (Backlog)
- [S45](S45-hover-tooltip-with-all-visible-values.md) Hover tooltip with all visible values (Backlog)
- [S46](S46-range-selection-with-statistics.md) Range selection with statistics (Backlog)
- [S47](S47-overview-minimap-with-brush.md) Overview minimap with brush (Backlog)
