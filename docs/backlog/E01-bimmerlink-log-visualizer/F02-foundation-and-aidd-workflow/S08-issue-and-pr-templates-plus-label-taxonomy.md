# Issue and PR templates plus label taxonomy

## User story

As the maintainer, I want templates that encode the story format and definition of done so that agent-authored PRs are consistent and traceable to a story.

## Acceptance criteria

- [x] Issue forms for epic, feature, user story and bug
- [x] PR template with `Closes #n`, test evidence, screenshots checklist
- [x] Labels documented: type, area, `mvp`
- [x] Project board status flow documented (Backlog > Ready > In progress > In review > Done)

## Definition of done

- [x] Tests added/updated (unit and, where relevant, e2e on the `Example/` logs)
- [x] Lint, typecheck, tests and build pass in CI
- [x] Docs / AGENTS.md updated if conventions changed
