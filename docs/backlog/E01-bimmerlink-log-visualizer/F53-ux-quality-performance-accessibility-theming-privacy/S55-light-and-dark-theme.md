# Light and dark theme

## User story

As a BimmerLink user, I want the app to follow my system theme with a manual override so that it is comfortable in a garage or in daylight.

## Acceptance criteria

- [ ] `prefers-color-scheme` honoured; manual toggle persisted
- [ ] Chart palettes tuned for both themes with sufficient contrast
- [ ] No flash of wrong theme on load

## Definition of done

- [ ] Tests added/updated (unit and, where relevant, e2e on the `Example/` logs)
- [ ] Lint, typecheck, tests and build pass in CI
- [ ] Docs / AGENTS.md updated if conventions changed
