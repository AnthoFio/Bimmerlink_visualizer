# Auto-fit modes

## User story

As a BimmerLink user, I want 'fit all data' vs 'fit visible window' auto-scaling so that axes stay readable when I zoom in time.

## Acceptance criteria

- [ ] Per-chart switch: fit all / fit visible
- [ ] Default fit visible
- [ ] Padding of ~5% applied

- [ ] Tests added/updated (unit and, where relevant, e2e on the `Example/` logs)
