# Parameter selection and grouping

## Description

A side panel listing all log columns where the user toggles visibility, searches, groups by category, picks colours and applies presets.

## Outcome

selecting/unselecting any of the up-to-210 parameters is a one-click, instant operation.

## Done when

- selecting/unselecting any of the up-to-210 parameters is a one-click, instant operation.
- All 5 stories of this epic are done.

## Boundaries

- Out of scope for the whole initiative: backend and accounts, live OBD/ENET streaming, writing or editing logs, multi-log comparison.
- Belongs to sibling epics: Foundation and AIDD workflow; CSV upload and parsing; Parameter catalog enrichment; Dynamic chart rendering; Chart exploration interactions; Axis and scale control; Session persistence and export; UX quality: performance, accessibility, theming, privacy.
