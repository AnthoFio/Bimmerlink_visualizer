# Chart exploration interactions

## Description

Direct-manipulation tools to explore events inside a log: zoom, pan, synchronised cursor, tooltips and range statistics.

## Outcome

the user can find a knock/misfire event and read exact values without leaving the chart.

## Done when

- the user can find a knock/misfire event and read exact values without leaving the chart.
- All 5 stories of this epic are done.

## Boundaries

- Out of scope for the whole initiative: backend and accounts, live OBD/ENET streaming, writing or editing logs, multi-log comparison.
- Belongs to sibling epics: Foundation and AIDD workflow; CSV upload and parsing; Parameter catalog enrichment; Dynamic chart rendering; Parameter selection and grouping; Axis and scale control; Session persistence and export; UX quality: performance, accessibility, theming, privacy.
