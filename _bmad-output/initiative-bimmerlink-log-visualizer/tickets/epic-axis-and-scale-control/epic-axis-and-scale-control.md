# Axis and scale control

## Description

Let the user take control of what each axis shows: manual Y ranges, auto/fit modes, normalised overlay, axis assignment and the X (time) window.

## Outcome

the user can make any two channels comparable and focus on a precise value range or time window.

## Done when

- the user can make any two channels comparable and focus on a precise value range or time window.
- All 5 stories of this epic are done.

## Boundaries

- Out of scope for the whole initiative: backend and accounts, live OBD/ENET streaming, writing or editing logs, multi-log comparison.
- Belongs to sibling epics: Foundation and AIDD workflow; CSV upload and parsing; Parameter catalog enrichment; Dynamic chart rendering; Parameter selection and grouping; Chart exploration interactions; Session persistence and export; UX quality: performance, accessibility, theming, privacy.
